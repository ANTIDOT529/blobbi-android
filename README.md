# Blobbi

A colorful slime puzzle for Android. Drop pieces onto an 8×8 board, merge same-colored slimes into bigger blobs and pop them at 9 cells.

![Screenshot 1](screenshots/1.png) ![Screenshot 2](screenshots/2.png) ![Screenshot 3](screenshots/3.png)

## Features
- Chain pops for combos, clear rocks, rainbow slimes join any colors
- 35 skins, 63 achievements, daily tasks
- Colorblind-friendly markers
- English and Russian
- Works offline
- No real-money purchases; optional rewarded ads only

## Download
Get the latest APK from the [Releases page](../../releases/latest). Android 7.0+ is required. You will need to allow installation from this source.
The SHA-256 checksum is listed in each release.

Also available on [RuStore](https://www.rustore.ru/catalog/app/com.blobbi.game).
